# ActiveStride Marketing Site

ActiveStride is a marketing site for a high-performance sportswear brand. The site is distributed as compiled Flutter Web assets and showcases the Spring Collection 2025 campaign. All messaging and layout decisions are derived from the latest approved design mocks (see screenshots in the repository issue tracker).

## Overview
The landing page leads with a hero banner featuring marathon imagery and a "Spring Collection 2025" headline, paired with calls to action for shopping and learning more. Subsequent sections promote performance statistics, new arrivals, the brand story, category navigation, testimonials, trusted brands, service assurances, and newsletter signup. The footer includes quick links for shop, support, and social channels.

## Visual Highlights
- **Hero Section:** Full-width imagery of an athlete during a race, headline "Engineered for Sport. Built for Performance." and buttons for "Shop Now" and "Learn More".
- **Performance Metrics:** Highlight cards showing 50K+ happy athletes, 500+ products, 98% satisfaction rate, and 24/7 support.
- **New Arrivals Carousel:** Product cards for footwear, training apparel, and equipment. Each card displays price, discount (where applicable), category label, and available color variations.
- **Brand Story Panel:** Split layout with a play button over a track image and copy emphasizing innovation, sustainable materials, and rigorous testing.
- **Category Grid:** Three cards for Footwear, Apparel, and Equipment with descriptive overlays.
- **Call to Action Banner:** Autumn cycling background with button labelled "Explore Collection".
- **Testimonials:** Three customer testimonials with five-star ratings and roles (marathon runner, professional athlete, fitness coach).
- **Trusted Brands & Services:** Logos for Nike, Adidas, Puma, Under Armour, Reebok, New Balance, plus service icons for shipping, payments, support, and quality guarantee.
- **Newsletter Signup:** Dark section encouraging visitors to subscribe for offers and updates, including privacy consent text.
- **Footer:** Brand description, shop and support links, and social media icons.

## Technology Stack
- **Framework:** Flutter Web
- **Languages:** Dart (source, not included) compiled to JavaScript, HTML, and CSS
- **Assets:** Images, icons, and fonts packaged within the Flutter build output

## Content Strategy
- Maintain messaging consistency with the "Engineered for Sport" brand voice.
- Ensure CTA labels remain action-oriented ("Shop Now", "Explore Collection").
- Preserve data points (50K+ athletes, 500+ products, 98% satisfaction, 24/7 support) unless marketing provides updated numbers.
- Testimonials should include full names, roles, and short performance-focused quotes.

## Working With the Build
1. Install the Flutter SDK (3.19 or later recommended).
2. Retrieve the original Flutter project (not included in this repository) or work from source control where it resides.
3. Run `flutter build web` to regenerate the `build/web` output.
4. Replace the assets in this repository with the contents of the new `build/web` directory.
5. Verify the site locally by serving the output with any static web server (e.g., `python3 -m http.server`).
